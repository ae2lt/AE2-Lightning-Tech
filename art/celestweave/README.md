# 苍穹织雷：雷电灵甲

静止时即可辨认完整的灵甲轮廓。肩部外扩、胸部收腰，前臂与胫部各自凝聚；面部、胸腹中央和关节留空。采用方形截面、平直表面和小幅折角，肩线、胸甲、护臂与靴筒贴合 Minecraft 的方块轮廓；前后错开的两层能量保留场的空间感。穿戴外观没有实体甲片或机械固定件。

雷纹由 GLSL 生成并量化为像素折线：每个场面包含三条像素折线主脉及分叉支流，常态可见，沿路径游走的亮度变化表现电流。无须位图贴图或第三方光影包。

## 内核配色

- 未装内核：淡蓝色。
- 任一已穿戴且槽位匹配的苍穹部件装有结构内核：整套变为紫色。
- 全部内核卸下：立即恢复淡蓝；背包或手持内核不触发变色。
- 状态读取复用 `CelestweaveArmorState.hasCore`，只读客户端同步的装备组件。
- 相位锁定投影使用紫色：现有 `PhaseLockService.shouldRemainLocked` 要求胸甲锚点持续装有内核，失效会解除投影；无需暴露私有内核组件。

## 渲染与资源

`src/main/java/com/moakiee/ae2lt/client/armor/` 包含场几何、姿态继承和渲染层；`src/main/resources/assets/ae2lt/shaders/core/armor/` 包含程序化材质。四槽独立，支持标准与细手臂。

使用自发光颜色、普通半透明混合、深度测试和仅颜色写入，保持日光下的蓝紫色及可见皮肤。自发光不代表会照亮周围方块。没有受击事件驱动的闪光逻辑；当前动画是常态雷纹中的电流变化。
