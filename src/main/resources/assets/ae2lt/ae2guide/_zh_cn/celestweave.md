# 苍穹织雷

  <ItemIcon id="ae2lt:celestweave_oculus" />
  <ItemIcon id="ae2lt:celestweave_core" />

**苍穹织雷**是模块化护甲。每件护甲都有独立的 FE 缓存、网络绑定、核心槽与模块槽。

| 部件 | 护甲栏位 |
|------|---------|
| 苍穹织雷·瞳 | 头盔 |
| 苍穹织雷·心 | 胸甲 |
| 苍穹织雷·径 | 护腿 |
| 苍穹织雷·阶 | 靴子 |

## 装配

每件护甲都需要在 <ItemLink id="ae2lt:overload_device_workbench" /> 中单独装配：

1. 放入护甲；护甲会绑定到工作站所在的 ME 网络
2. 在核心槽安装 <ItemLink id="ae2lt:ultimate_overload_core" />
3. 安装 1 个可选能量模块，以及对应部件可用的功能模块
4. 穿戴护甲后，默认按 G 打开过载设备中枢，启用、停用或配置模块

每件护甲可以安装任意数量的兼容模块，但同类模块的安装数量与互斥关系仍然有效，且能量模块只能安装 1 个。未安装能量模块时，每件护甲可存储 10,000,000 FE。T1 / T2 / T3 能量模块会将护甲容量提升至 1,000,000,000 / 5,000,000,000 / 20,000,000,000 FE。

## 运行条件

模块只有在护甲已穿戴、安装核心、模块已启用时才会进入运行态。运行中的模块会消耗已穿戴苍穹织雷部件中的 FE，并通常从绑定 ME 网络中消耗闪电。

当 FE 或所需闪电不足时，对应效果无法维持。

## 头部模块

| 模块 | 作用 |
|------|------|
| 夜视模块 | 运行时持续维持夜视效果 |
| 水下呼吸模块 | 运行时持续维持水下呼吸效果 |
| 饱和模块 | 周期性将饥饿值与饱和度恢复至满值，恢复时消耗高压闪电 |

## 胸部模块

| 模块 | 作用 |
|------|------|
| 触及扩展模块 | 增加方块 / 实体交互距离，可配置为 1x、2x 或 4x |
| 矩阵护盾模块 | 免疫环境伤害并自动灭火，普通伤害约 80% 减免，硬伤害约 50% 减免 |
| 相位护盾模块 | 完全阻止受到的伤害并自动灭火，按阻止量消耗极高压闪电 |
| 反伤模块 | 将来自攻击者的部分伤害反弹，消耗 FE 与高压闪电 |
| 不死模块 | 拦截致死伤害，消耗大量 FE 与极高压闪电 |
| 净化模块 | 移除并阻止配置允许的状态效果；默认只处理负面效果 |
| 享辐模块 | 完全阻止新增辐射暴露并免疫辐射伤害；处于有效辐射环境时每秒恢复 1～5 颗心，强度随辐射等级提高 |
| 激光防护模块 | 完全吸收 Mekanism 激光；按当前 Mekanism 能量换算比例，将实际吸收的焦耳转化为 FE，依次充入胸甲与整套苍穹织雷 |
| 相位锁定模块 | 提供四个可独立开关的子功能：盔甲锁定、飞行锁定、阻止外力拉动、阻止外部传送，详见下文 |
| 过载内核模块 | 解锁整套护甲的闪电代偿；极高压闪电 不足时优先使用现有 极高压闪电，再按 16 高压闪电 = 1 极高压闪电 补足缺口 |

矩阵护盾与相位护盾属于同一安装组，胸甲上只能安装其中一种。

### 相位锁定

相位锁定模块以胸甲为控制器，在设备中枢中提供四个可独立开关的子功能：

* **盔甲锁定：** 将当前穿戴的整套苍穹织雷转移到玩家专属的四个私有相位槽；各护甲栏会显示相位锁定投影，表明你的对应护甲正由私有相位槽保管。真护甲在私有槽中照常运行，锁定期间新穿上的苍穹织雷部件也会自动纳入。投影没有附魔光效，无法取出或交易；单个投影被替换或移除时，消耗 1,000,000 FE 与 16 极高压闪电原位重建，支付失败则整体解除锁定并穿回全部真护甲。
`你可以理解为灵魂绑定`
* **飞行锁定：** 冻结当前飞行状态，使落地后不自动退出飞行，并拒绝外部系统改写。它同时识别运行中的创造/相位飞行模块、原版游戏模式飞行以及 NeoForge `CREATIVE_FLIGHT` 属性，但自身不会授予飞行能力。
* **阻止外力拉动：** 拦截水流、风扇、击退等外部系统对移动的改写；玩家自身操作与装备提供的移动不受影响。
`具体例子：无视机械动力鼓风机的推拉`
* **阻止外部传送：** 拦截外部坐标改写、传送与跨维度切换；玩家正常移动不受影响。
`具体例子：无视混沌龙强行传送`

## 腿部模块

| 模块 | 作用 |
|------|------|
| 创造飞行模块 | 提供悬停与翼装滑翔，可配置速度与飞行惯性 |
| 相位飞行模块 | 提供悬停与相位翼滑翔；相位模式统一决定飞行时是否穿墙 |

创造飞行与相位飞行属于同一安装组，护腿上只能安装其中一种。相位飞行安装后默认停用，需要在设备中枢中启用。

两种飞行模块共用原版式操作：空中单击空格展开翼装滑翔，快速双击空格切换悬停。滑翔时持续按住空格会沿视线方向推进；悬停时空格上升、Shift 下降。同时按住 Shift 与空格时垂直输入互相抵消，并对其他模组表现为潜行状态。只有相位飞行可配置相位模式；开启后悬停与滑翔均可穿过方块。飞行锁定由胸甲的相位锁定模块统一控制。

## 足部模块

| 模块 | 作用 |
|------|------|
| 冲刺模块 | 默认按 V 向视角方向冲刺，冷却 40 tick |
| 挖掘适应模块 | 减轻水下与空中挖掘惩罚 |
| 步行辅助模块 | 分别调节步行、奔跑、潜行速度（0.5×～4×）与自动爬坡高度（0.6～3 格） |

## 消耗说明

多数运行中的普通模块每 tick 额外消耗 1 高压闪电。创造飞行与相位飞行在移动时消耗更多高压闪电；相位模式实际穿行时改为消耗极高压闪电。护盾、净化与不死在短时间内连续触发时，消耗会逐次提高。胸甲安装过载内核模块后，整套护甲的 极高压闪电 缺口可以按 16 高压闪电 = 1 极高压闪电 代偿。
