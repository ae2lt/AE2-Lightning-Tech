# 苍穹拟态手杖

<ItemImage id="ae2lt:celestweave_mimicry_staff" />

苍穹拟态手杖同时提供钻石级的镐、剑、斧能力，挖掘效能为 8，基础攻击伤害为 7，攻击速度为 1.6。安装模块增加能力，无需切换工具类型。

## 装配和配置

手持手杖，按**装备配置快捷键（默认 G）**，在原有过载设备配置界面选择手杖页。潜行右键空气也可打开同一界面。选中模块后，在下方参数区调整；速度、熔炼和收集增强使用列表中的开关。主手、副手均可识别。

把手杖放入**过载设备工作台**，在模块输入槽安装模块；拆卸沿用工作台模块列表。每类只能装一个，下界合金与最高采集等级模块共用等级槽，升级时先取出旧等级模块。模块数据与附魔随拆装保存，手杖无需额外结构核心。

| 模块 | 效果 |
| --- | --- |
| 鹤嘴锄 | 铲和锄同时可用；土地操作选择关闭、耕地或铲路，熄灭营火始终可用 |
| 剪切 | 剪刀适用方块采集、剪羊毛、雕刻南瓜和采集蜂巢 |
| 刀具 | 农夫乐事厨刀切割、采集及原生刀具击杀掉落识别 |
| 扳手 | AE2 原生旋转和拆卸；Mek 默认配置物品，可选择其他资源、旋转或拆卸 |
| 下界合金采集 | 下界合金采集等级，效能 9 |
| 最高采集等级 | 解除普通工具材质等级门槛，效能仍为 9；不解除基岩等方块自身的破坏限制 |
| 速度调节 | 目标耗时 = 基础时间 + 原始耗时 × 倍率 |
| 伤害增强 | 调节攻击伤害与范围，默认 10、单体；承载剑类战斗附魔 |
| 采集增强 | 普通、时运 III+、精准采集 I 三选一，并承载工具类附魔 |
| 自动熔炼 | 熔炼本次产物一次，默认关闭 |
| 收集增强 | 把本次产物放入背包，余量正常掉落，默认关闭 |

## 工具交互

木材去皮、刮氧化层和去蜡自动按目标执行。土地动作只执行已选择的操作，不会因耕地失败而改为铲路。

Mek 配置用途沿用原生侧面配置与管线交互：通常普通右键打开机器，潜行右键配置。默认配置物品；旋转或拆卸需要明确选择。AE2 的操作不受 Mek 设置影响。

## 攻击范围、伤害与处决

在装备配置界面选择伤害增强模块，分别调整攻击范围和伤害：

- 范围为单体、原生横扫、3×3、5×5、7×7。方形范围以主目标命中前的位置为中心，按实体碰撞箱相交判定，垂直范围为下方 1 格至上方 2 格。满蓄力主目标成功命中后才触发，不递归扩散；跳过盟友、自己的宠物、盔甲架和被墙遮挡的附加目标。附加目标仍逐个经过原生攻击事件和附魔处理。
- 基础攻击伤害为 **1、5、10、20、100、500、无限**。这些数值包含玩家基础伤害，附魔、蓄力、暴击、护甲等仍沿原生流程处理。500 需要安装现有**过载内核模块**；无限需要**多维处决模块**。选项跳过尚未解锁档位；卸下解锁模块立即回落到最高可用档位。
- 无限在伤害调用处使用有限的 极大有限伤害值，避免无穷属性或 NaN；附魔属性栏仍显示有限值，所选无限档位以配置页为准。关闭处决时仍可被原生伤害保护拒绝。
- 安装现有**过载处决模块**或**多维处决模块**后，在该模块参数中选择关闭、正常死亡、强制移除。需要伤害增强模块与满蓄力近战；默认正常死亡。关闭时仅保留所选原生伤害；开启后复用电磁炮同一套血量记录、衰减、死亡归属与移除实现，遵守处决总开关及玩家目标保护。
- 普通伤害先处理，过载血量记录随后扣减本次攻击伤害，与电磁炮顺序一致。每个接受过载结算的目标额外消耗 **20,000,000 FE**，并预留该次命中的 1,000 FE；不足时只保留可支付的普通攻击。多维处决没有这笔额外费用。
- 方形范围内每个成功命中单独收取 1,000 FE，按距主目标从近到远处理，电量不足即停止。原生横扫沿用原生一次挥击收费和副目标伤害规则，额外副目标不进入手杖处决；需要范围处决时选择方形范围。

## 闪电消耗

日常挖掘、剪切、砧板、扳手，以及 1／5／10／20 伤害的单体近战仍按原 FE 规则运行。强化战斗额外从绑定的 ME 网络提取闪电。把手杖放入联网的过载设备工作台即可自动绑定；工作台所在区块必须已加载，且网络正常供能。绑定沿用电磁炮的距离与维度规则，保存后仍保留。

| 攻击配置 | 每次原生命中的闪电费用（默认） |
| --- | --- |
| 1、5、10、20 伤害，单体 | 无 |
| 100 伤害 | 32 极高压 |
| 500 伤害 | 96 极高压 |
| 无限伤害 | 256 极高压 |
| 满蓄力且启用处决 | 极高压费用至少 256，与伤害档位取较高值，不重复相加 |
| 满蓄力横扫、3×3、5×5、7×7 | 额外 1 高压；方形范围按每个实际命中分别收费，原生横扫按一次挥击收费 |

三级极高压费用直接沿用电磁炮配置 `railgun.energy.ehvCostTier1/2/3`。过载内核启用 **16 高压抵 1 极高压**补偿；先使用极高压，缺额才用高压补足。多维处决仍免除过载处决的 2000 万 FE 附加费，但不免闪电费。

命中前检查并预扣整笔闪电；不足时不产生该次攻击或处决效果，也不扣基础 FE。原生命中与处决均未生效时退回预扣闪电。方形范围按近到远处理，剩余闪电或 FE 不足就停止。全额费用的模拟与实际提取不一致时退回已提取部分。

装备配置界面的伤害增强和处决模块下显示当前满蓄力攻击的高压、极高压费用，只读且随配置变化。状态“战斗资源不足”指当前战斗配置缺少 FE、闪电或有效网络；普通工具操作仍单独检查 FE。

## 附魔

本体不能直接附魔。把**增强模块与附魔书放入铁砧**附魔，再安装模块。

采集增强模块接受工具类附魔，包括第三方按工具定义声明的附魔，仅明确排除效率与直接精准采集。普通模式不启用时运或精准采集，其他工具附魔仍按条件生效。时运模式为 `max(3, 模块有效时运等级)`，精准模式固定 I。

伤害增强模块接受锋利、亡灵杀手、节肢杀手、抢夺、击退、火焰附加、横扫之刃。农夫乐事背刺还需要刀具模块；遵循原生位置与伤害规则。互斥附魔会阻止安装或切换，不会同时运行。

## 挖掘时间

基础时间可选 0、3、5、10、20 tick；原始耗时倍率可选 0.01、0.05、0.1、0.2、0.5、1。20 tick 为一秒。基础时间在缩放后相加，例如原始 40 tick、基础 3、倍率 0.1，结果为 7 tick。

玩家效果及方块自定义挖掘逻辑先参与原始进度，再应用一次转换。速度模块不会给予本来不允许的采集资格。

## 消耗与产物

容量为 **100,000,000 FE**，通过支持物品 FE 充电的设备充能。合成产物初始无电。每个原生耐久消耗点折算为 **1,000 FE**；挖掘和攻击每次 1,000 FE，剪切及砧板等沿用原生成功操作结算。自动熔炼与收集增强不重复收费。原生不扣耐久的扳手配置也不额外收费，但仍需要至少 1,000 FE 才可操作。

电量不足时停用工具操作，保留手杖、模块和设置；仍可打开配置页。耐久附魔不会降低 FE 消耗，经验修补不会充电或消耗经验。神化的自然祝福按其原生等级费用换算 FE，并在催熟前检查完整费用。

产物顺序固定为：原生战利品／剪切／砧板配方 → 自动熔炼一次 → 插入背包 → 余量落地。自动熔炼使用世界当前熔炉配方，不额外发放熔炉经验。收集增强只处理这次操作的产物，不吸取附近物品，也不主动回传 ME。

农夫乐事砧板可以使用已安装的多种工具能力，原生输入扣除与时运产出只结算一次。砧板以外的厨刀切食物和生物击杀掉落不接入手杖的熔炼／收集增强流程。

## 相位锁定

装备配置页的参数列表末尾可开启相位锁定，默认关闭，无需额外模块。真身移入服务器私有槽，原格显示手杖投影。使用、附魔、FE 和闪电都在唯一真身上结算。

投影不可提取、丢弃或移动，包括界面交换和 F 键主副手交换。整理位置、装卸模块前先解锁；解锁不消耗资源并返回原件。投影没有真实模块、物品容器或第三方组件，不能拿去拆卸。

投影丢失或重生后自动补位，旧投影失效，真身内容不会被复制。原格被其他物品占据时先移到空位；背包满时等待空间。已适配气动工艺漏斗、犬牙钓竿和机会方块物品栏奖励，并保留提取、界面和掉落实体拦截。
