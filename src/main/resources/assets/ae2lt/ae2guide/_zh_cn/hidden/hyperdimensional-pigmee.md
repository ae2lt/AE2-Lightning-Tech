# 超维猪咪研究

这份记录不会出现在通常的指南目录里。把鼠标移到**超维猪咪**上并长按指南键，就能
再次翻开它从时空彼端带回来的秘密。

## 笔记中的仪式

每本写满的研究笔记都会列出九件祭品。开头三件始终相同，依次是：

1. **猪咪核心**
2. **不死模块**
3. **相位锁定模块**

余下六件由每本笔记自行决定，所以真正的答案要以手中这本笔记为准。

先把笔记丢到**大气电离仪正上方**，再照着笔记从上到下，把九种材料一件件分开投入。
每堆可以多放，但仪式只会从中取走一件。几件材料若几乎同时脱手，也不会因为先后难以
分辨而失败。

最后给大气电离仪装入**雷暴凝核**并启动它。若祭品与顺序无误，闪电会把九件祭品一并
带走，留下一只巨大的**超维猪咪**。猪咪核心、不死模块与相位锁定模块会依次在雷光中
破碎；五秒后，猪咪恢复原样，此时才能捡起。

若材料都对、顺序却错了，祭品仍会被闪电烧掉，并可能留下焦黑的残片。研究笔记不会
消失；成功完成过的笔记会留下作为纪念，但无法再次举行仪式。

## 仅余的一次转换

把超维猪咪与下列任意一件物品放在一起合成，它会替你完成一次跨越界限的转换。力量
耗尽后，超维猪咪会变回普通猪咪。

| 目标物 | 转换结果 |
|---|---|
| 避雷针 | 无限高压闪电元件 |
| 雷暴凝核 | 无限极高压闪电元件 |
| 闪电坍缩矩阵 | 无限闪电坍缩矩阵元件 |
| 大宗闪电存储组件 | 无限存储元件 |
| 天枢过载主核心 | 天枢多维主核心 |
| 天枢物质扭曲矩阵过载主核心 | 天枢物质扭曲矩阵多维主核心 |

创造猪咪也能完成这些转换，而且不会失去力量；它还能复制超维猪咪。JEI 或 EMI
不会展示这些特殊合成，以上记录就是它们留下的全部线索。
