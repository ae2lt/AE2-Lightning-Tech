# Hyperdimensional Pigmee Research

This record does not appear in the ordinary guide index. Hover over a
**Hyperdimensional Pigmee** and hold the guide key to reopen the secret it carried back from
beyond space and time.

## The ritual in the note

Every completed Research Note lists nine offerings. The first three are always:

1. **Pigmee Core**
2. **Undying Module**
3. **Phase Lock Module**

The remaining six are chosen separately for every note, so always follow the list written in the
note you are holding.

First, drop the note directly above an **Atmospheric Ionizer**. Then follow its list from top to
bottom, dropping the nine materials separately. A dropped stack may contain extras, but the ritual
takes only one item from each. Materials released almost together will not fail merely because
their order is too close to distinguish.

Finally, load a **Thunderstorm Condensate** into the Atmospheric Ionizer and activate it. If every
offering and its order are correct, lightning carries the nine offerings away and leaves behind an
enormous **Hyperdimensional Pigmee**. Pigmee Core, Undying Module and Phase Lock Module shatter in
the lightning one after another. Five seconds later the Pigmee returns to normal and can be picked
up.

If the materials are correct but their order is not, the lightning still burns the offerings and
may leave charred fragments. The note survives. After a successful ritual it remains as a keepsake,
but it cannot be used for another ritual.

## One remaining conversion

Craft a Hyperdimensional Pigmee together with any one of the items below. It will perform one
boundary-crossing conversion for you, then return to being an ordinary Pigmee.

| Target | Result |
|---|---|
| Lightning Rod | Infinite High Voltage Lightning Cell |
| Thunderstorm Condensate | Infinite Extreme High Voltage Lightning Cell |
| Lightning Collapse Matrix | Infinite Lightning Collapse Matrix Cell |
| Bulk Lightning Storage Component | Infinite Storage Cell |
| Tianshu Overload Main Core | Multidimensional Tianshu Core |
| Tianshu Matter Warping Matrix Overload Main Core | Multidimensional Matrix Core |

The Creative Pigmee can perform the same conversions without losing its power, and it can also
copy a Hyperdimensional Pigmee. JEI and EMI do not show these unusual recipes; this record is the
complete clue they leave behind.
